# ux: make chalk next and doctor concise, prioritized, and profile-aware

- Remaining blocked, needs-criteria, dependency, and human-input items are summarized by category.
- A verbose flag reveals the full current listing without losing information.
- A fixture matching Chalk own mixed blocked/duplicate/needs-criteria queue proves the useful action appears first.

- Agent readiness reports resolved role profiles, capabilities, independence state, and exact remediation commands.
- Manual mode is presented as a valid path rather than a failed autonomous setup.
- Neither command performs a live model call.
- Existing JSON output remains stable or receives an explicit versioned migration.
- Help and snapshots remain readable without ANSI color.
